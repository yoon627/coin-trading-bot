# 1년 fixture 파라미터·아이디어 탐색

**질문**: 운영 8종 최근 1년 일봉에서 지금 라이브(`combined`, TP5/SL5/트레일2/arm3/hold1)보다 나은 설정이 있나. 세 축을 같은 기준으로 판정한다 — 진입(`kValue`)·청산 파라미터 51,480 좌표(Stage A), 라이브에 없는 청산 아이디어 3종(Stage B), repo 에 없던 지표로 만든 진입 전략 10종 × 같은 exit 공간 39,600 좌표(Stage D).

**답**: **사전고정 기준으로는 없다.** Stage A 는 22,952 고유 행동 중 3건이 게이트를 전부 통과했지만 null 대조군의 max-statistic 을 넘지 못했고, Stage B(신규 청산 아이디어 75셀)와 Stage D(신규 지표 진입 전략 10종 × exit 공간, 고유 13,580)는 통과 0건이다.

## 왜 "1등"이 아니라 게이트인가

[[yearly-strategy-comparison]] 이 이미 잰 사실 — 이 fixture 에서 선택창→검증창 순위상관 ρ=0.32, 전체 1위(`combined/live`)가 검증창 11위. **한 구간의 최고점을 고르는 행위 자체가 과적합**이라 이 작업은 "1등 찾기"가 아니라 사전고정 게이트 통과 여부를 묻는다. 기준·그리드·seed 는 결과를 보기 전에 커밋했다(사전고정 plan, `391118e`).

관측치는 마켓별 **paired delta**(후보−baseline)의 중앙값과 양수 마켓 수다. `median(후보) − median(baseline)` 은 마켓 효과가 섞여 부호까지 갈릴 수 있다.

| 게이트 | 기준 |
|---|---|
| G1 선택창(193봉) | paired delta 중앙 ≥ +2.0%p **그리고** 양수 마켓 ≥ 6/8 |
| G2 검증창(122봉) | 중앙 ≥ 0 그리고 양수 ≥ 5/8 (8마켓에선 마켓 수 조건이 중앙값 조건을 흡수한다) |
| G3 plateau | 고유 좌표 이웃 ≥70% 가 G5+G1 통과 |
| G4a 시간 독립 국면 | `bull`·`p2024h2`·`p2025h1` **각각** 중앙 ≥ −1.0%p |
| G4b bear | 중앙 ≥ −1.0%p (yearly 에 포함 — robustness 표기 전용) |
| G5 표본 | 창별 거래수 ≥ 8, 0거래 마켓 ≤ 1 |
| G6 낙폭 | MDD 중앙 delta ≤ +2.0%p, 최악 ≤ baseline×1.5 |
| G7 비용 | 수수료 2배·4배에서도 G1 유지 |

임계값(2.0%p·70%·1.5배)은 **운영상 최소효과·리스크 허용치**이지 통계적 유의 임계가 아니다 — 마켓 상관 0.49, 실효 독립 표본 2~3.

## Stage A — 진입·청산 스윕 (51,480 좌표)

`arm ≤ trail/(1−trail/100)` 인 조합은 트레일링 발동식상 전부 같은 동작이라 그리드에서 뺐다(Cartesian 93,600 → 51,480, −45%). 실행 후 거래 지문으로 접으니 **고유 행동 22,952**.

| 게이트 | 여기서 탈락 |
|---|---|
| G5 | 974 |
| G1 | 21,513 |
| G3 | 330 |
| G6 | 132 |
| G2·G4a·G4b·G7 | 0 |

살아남은 3건은 전부 같은 행동 계열이다 — `combined` **k0.3 / SL 7% / 트레일링 1.5%(arm 0) / hold 1 / 필터 off / TP 8~off**. 즉 *"5% 고정 익절로 끊지 말고 타이트한 트레일링으로 끌고 가되 손절은 넓게"*.

| 지표 | 값 |
|---|---|
| 선택창 paired 중앙 | **+4.92%p** (양수 7/8) |
| 검증창 | +2.13%p (5~6/8) |
| bull(2023-11~2024-06) | +6.5 ~ +7.0%p |
| **p2024h2**(2024-06~12, 강한 상승) | **+10.3 ~ +11.9%p** |
| **p2025h1**(2025-01~07, 혼조·약세) | **+11.2 ~ +12.5%p** |
| bear(구간 중복 — 독립 증거 아님) | +2.60%p |
| MDD 중앙 delta / 최악 | +0.30%p / 12.6%p |
| 거래수·노출 | 118~119 · 0.08 (baseline 84 · 0.04) |
| 승률 / 실측 손익분기 승률 | 65% / 48~49% |
| 수수료 2배·4배 | +4.51 / +3.71%p |

## 국면을 넷으로 늘리면 (2026-09-04 추가 측정)

처음 판정은 시간 독립 holdout 이 `bull` 하나뿐이었다. 같은 시점 중립 규칙으로 겹치지 않는 구간 둘을 더 수집해(`p2024h2` 강한 상승 / `p2025h1` 혼조·약세) G4a 를 **세 국면 각각 통과**로 강화했다.

**같은 3후보가 그대로 살아남았고, out-of-sample 성적이 선택창보다 좋았다** — 선택창 +4.92%p 인데 p2024h2 +10.3~11.9%p, p2025h1 +11.2~12.5%p, bull +6.5~7.0%p. 네 국면(상승·혼조·하락·하락) 전부에서 baseline 을 이겼다는 뜻이다. Stage D 는 국면을 늘려도 여전히 통과 0 이다.

이것이 **사전고정 판정을 바꾸지는 않는다**(아래) — null 대조군은 선택창 통계에만 걸려 있고, 이 out-of-sample 증거를 반영하도록 규칙을 지금 고쳐 쓰면 결과를 본 뒤 기준을 바꾸는 것이 된다. 대신 **다음 판정의 사전고정을 새로 쓸 근거**로 남긴다.

## null 대조군이 판정을 뒤집는다

진입을 `(seed, market, 봉)` 순수 해시로 무작위화하고 **같은 exit 그리드**를 뒤진다(seed 91개, 진입 확률 = baseline 원시 신호 발생률 0.060). 상태 있는 RNG 를 쓰면 exit config 마다 진입 시점이 달라져 대조군 정의 자체가 무너진다.

| 변종 | 기준 | 1건 이상 통과한 seed | 평균 통과 수 | max-stat 95% | 23배 폭 환산 |
|---|---|---|---|---|---|
| **A (주 판정)** | 실제 라이브 `combined` | **0.0%** | 0.00 | 7.84%p | 13.60%p |
| B (진단용) | 같은 무작위 진입 | 85.7% | 259.18 | 15.64%p | 16.49%p |

**변종 B 는 계기 고장이다.** 후보·기준이 모두 무작위면 기준 자체가 형편없고 변동이 커서 delta 분포가 부푼다 — 잡음이 실제 탐색보다 500배 잘 통과한다(6.5% vs 0.013%). 그 분위수를 임계로 쓰면 사과-오렌지 비교라 A 만 판정에 쓴다.

A 의 결과는 두 방향을 동시에 가리킨다.

1. **게이트 스택은 무르지 않다** — 잡음 91회 탐색에서 통과 후보가 **한 건도** 나오지 않았다(실제 탐색은 3건).
2. **그러나 사전고정한 max-statistic 기준은 못 넘었다** — 잡음 탐색이 선택창에서 우연히 도달하는 최고 delta 의 95% 분위가 7.84%p(실제 탐색 폭 23조합으로 환산하면 13.60%p)인데 실제 후보는 4.92%p 다. Stage D 의 최고 근접값(+5.04%p)도 마찬가지로 못 넘는다.

둘이 갈리는 이유는 재는 대상이 달라서다. max-stat 은 G1(선택창 효과크기) **하나만** 보고, 통과율은 G2·G3·G6 까지 요구한다. 사전고정 문구가 max-stat 기준이므로 **그것을 따른다** — 결과를 본 뒤 더 유리한 기준으로 갈아타면 사전고정이 무의미해진다.

## Stage B — 신규 아이디어 (75셀, 통과 0)

Stage A 와 같은 지표·게이트(G3 제외 — 축당 값이 3개 미만이라 이웃이 정의되지 않는다). 기준은 라이브 현행.

- **레짐 필터**(현재가 < MA 면 매수 차단): MA10 −0.53 · MA20 0.00 · **MA50 −2.20%p**. 도움이 안 된다. 라이브 매수 경로에 이 필터가 없는 현 상태를 바꿀 근거가 없다.
- **ATR 가변 손절·익절**(트레일링 끈 상태에서 측정): 선택창 전 셀 ≤ 0. `hold 365` 계열은 −4 ~ −16%p 에 MDD 20~48%p 로 크게 나쁘다. 보유를 늘리면 노출이 0.04 → 0.2~0.4 로 뛰고 그 노출이 하락장에서 그대로 손실이 된다.
- **부분 익절**: 최고가 `2%@50% / TP 12%~off / h1` 로 **+1.21%p(6/8)**, 검증창 +0.18. 방향은 Stage A 생존자와 같지만(일찍 끊지 말 것) G1(+2.0%p)에 못 미친다.

G3 는 이웃이 G5 를 함께 통과할 때만 센다. 하락 국면에서는 **거래를 거의 안 한 좌표의 paired delta 가 양수**가 되므로, G5 없이 세면 "효과가 이웃으로 이어진다" 가 아니라 "이웃이 아무것도 안 한다" 로 plateau 가 채워진다.

## Stage D — 신규 지표 진입 전략 10종 (39,600 좌표, 통과 0)

repo 에 없던 지표로 진입 전략을 만들어 **같은 exit 공간·같은 게이트**에 태웠다: ADX/DMI · 돈치안 채널 돌파 · 켈트너 채널 · 슈퍼트렌드 · 스토캐스틱 · Williams %R · OBV · MFI · CCI · VWAP 밴드. 전부 D1·50봉 window 안에서 계산되고, 지표 수식은 각 전략 파일 안 private 으로 둔다(`Indicators.kt` 는 공유 자산이라 건드리지 않는다).

고유 행동 13,580 중 **G1 에서 12,879 전멸, 통과 0**. 다만 "전혀 아니다" 는 아니었다:

| 근접 후보 | 선택 중앙 %p | 선택 +마켓 | 거래수 |
|---|---|---|---|
| `obv_trend` TP8 / SL5 / 트레일1.5 / h5 | **+5.04** | 5/8 | 66 |
| `obv_trend` TP12 / SL5 / 트레일1.5 / h5 | +4.79 | 5/8 | 66 |
| `vwap_band` TP8 / SL10 / 트레일1.5 / h2 | +4.14 | 5/8 | 89 |

**효과 크기는 Stage A 생존자(+4.92%p)보다 컸는데 마켓 다수결(6/8)에서 떨어졌다** — 8마켓 중 5곳에서만 이겼다는 뜻이고, 그게 정확히 이 게이트가 거르려던 것이다(한두 마켓이 만든 우위). 세 후보 모두 트레일링 1.5%·arm 0 을 쓴다는 점은 Stage A·B 와 같은 방향이다.

## 읽는 법

1. **"더 나은 알고리즘을 못 찾았다"가 아니라 "이 표본·이 공간에서 사전고정 기준으로는 못 가린다"** 이다. 1년 8마켓의 실효 독립 표본이 2~3 이라 +4.9%p 짜리 효과는 잡음과 분리되지 않는다.
2. 그럼에도 **세 Stage 가 같은 방향을 가리켰다** — Stage A 생존자(트레일링 1.5·TP 사실상 off), Stage B 최고 셀(부분익절 2%@50% + TP 넓힘), Stage D 근접 후보(전부 트레일링 1.5·arm 0) 모두 "5% 고정 익절로 일찍 끊는 것"을 완화하는 쪽이다. 서로 다른 진입 신호에서 같은 청산 방향이 나온 것은 신호가 아니라 **청산 정책**이 지배적이라는 뜻일 수 있다. 가설로 삼을 만하지만 이 데이터로 확정할 수는 없다.
3. **라이브 파라미터는 바꾸지 않았다.** 리스크를 키우는 전이는 사람 승인이 필요하고([[strategy-evolution-expectations]]), 지금 근거는 그 승인을 요청할 수준이 아니다.
4. **국면을 넷으로 늘리자 후보의 out-of-sample 성적이 선택창보다 좋아졌다** — 과적합이라면 반대로 나왔어야 한다. 사전고정 규칙은 그대로 "발견 없음"이지만, **다음 사전고정을 holdout 기반으로 다시 쓰고 소액 전향 검증을 붙일 근거**로는 충분하다.
5. **진입 지표를 10종 더 넣어도 답이 바뀌지 않았다** — 탐색을 넓히는 방향의 수확체감이 실측으로 확인된 셈이다. 다음으로 유효한 것은 그리드를 더 뒤지는 게 아니라 **표본을 늘리는 축**이다 — 전향적 관찰(소액 카나리아·페이퍼), 국면 fixture 추가, 또는 M1 fixture([[reset-churn-measurement]] 후속).

## 한계

- 선택·검증은 여전히 **한 국면(하락) 안에서** 이뤄진다. 마켓 상관 0.49 → 그 창의 실효 독립 표본은 2~3 이고, **생존편향**(그 기간을 살아남아 상장 중인 종목)은 제거 불가다.
- 국면 holdout 은 셋(bull·p2024h2·p2025h1)이지만 각 구간의 로스터가 회전해 **네 국면 공통 마켓은 XRP·BTC 둘뿐**이다 — paired 마켓 교차검사는 3 미만이라 적용하지 않았다(교집합을 늘리려 선정 규칙을 손대면 그게 다시 선택 편향).
- bear 는 yearly 구간에 포함된다 — robustness 표기이지 독립 증거가 아니다.
- 엔진 한계 그대로: 단일 티커·단일 포지션·슬리피지 0·봉당 1회·intrabar 근사([[backtest-engine]]). 포지션 사이징·포트폴리오·마켓 선택은 이 엔진으로 잴 수 없다.
- 부분 익절은 두 다리를 한 거래로 **가중 합성**한 근사다(부분 체결 시각·다리 pnl 은 레코드에 남겨, equity 곡선과 노출은 체결 전 1.0 / 후 `1−f` 로 **구간별 정확히** 계산한다). 합성 레코드는 `pnl ↔ 가격` 불변식을 만족하지 않으므로 `partialFraction` 으로 식별한다.
- null 대조군의 진입 확률은 baseline 의 **원시 신호 발생률**로 맞췄다 — 실현 진입 수는 exit 설정에 따라 달라지므로 근사다.
