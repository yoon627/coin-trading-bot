# Decisions

- **판정: 게이트 결함이 아니다.** 근거 셋 —
  1. 네 가지 세는 법(원안 / 자기별칭 제외 / 지문 dedup / 둘 다) 전부에서 A 탈락(6/10·5/9·6/10·5/9),
     공표된 생존 3좌표는 전부 통과. 세는 법이 판정을 바꾸지 않는다.
  2. 그리드 51,480 좌표 중 자기별칭 이웃 보유 34,008(별칭 인스턴스 100,056)인데
     **통과→탈락 17건, 탈락→통과 0건**. 별칭은 판정을 무르게 만들지 엄하게 만들지 않는다.
  3. 구조적 편향 변호는 산술로 기각(위 Progress).
- **A 가 고립 스파이크라는 뜻은 아니다** — 격자 밖 해상도로 트레일링을 스캔하면 1.00 +6.27(8/8) →
  1.50 +3.28(7/8) → 2.00 +0.80(5/8) 로 단조 감쇠한다. 능선이지 칼날이 아니다.
  **다만 "실패한 넷은 이미 나쁘다고 아는 방향" 이라는 변호는 철회한다 (변경 이유: 전역 통과율 측정 결과와 충돌).**
  전역으로 죽은 방향은 필터↑(0.3%) 하나뿐이고 보유↑ 53.1% · SL↓ 62.9% 는 대체로 통과한다 —
  A 의 실패 넷 중 셋은 A 국소 사실이고, 그것이 G3 가 재려던 바로 그것이다.
  생존 3좌표도 보유↑·필터↑ 를 똑같이 잃고 통과했으므로 그 변호는 A 와 E 를 가르지도 못한다.
- **A 와 E 를 가른 것은 축 개수가 아니라 G1 마진**이다(+3.28 vs +4.92, 절대임계 2.0%p).
  즉 G3 는 이름과 달리 사실상 마진 테스트로 작동한다 → #185 로 분리.
- **승격값 1.5 는 격자 하한이 만든 값**이라는 부수 발견 → #184 로 분리. 지금 라이브를 바꾸지 않는다
  (D1 stale-peak 아티팩트일 수 있어 240분봉 계기 재판정이 선행돼야 한다).
- **`StrategySearchGates.kt` 는 한 글자도 건드리지 않는다.** 사전고정 게이트를 결과 본 뒤 고치면
  다중비교 회계가 무너진다. 눈금 문제는 #185 에서 **다음** 사전고정 설계에 반영한다.
- **승격 근거는 7국면 확증 하나뿐이라고 문서에 명시한다.** 이 감사는 승격을 정당화하지 않는다.
  G3(선택창 파라미터 공간의 매끄러움)와 7국면 확증(미관측 구간 성과)은 서로 다른 것을 재고,
  A 는 전자를 실제로 통과하지 못한다. 이 사실을 wiki 승격 절에 남긴다.
- **감사는 env 게이트 테스트로 둔다**(`RUN_PLATEAU_AUDIT=true`) — 51,480 좌표 순회라 CI 상시 실행 대상이 아니다.
  기존 `RUN_RESET_POLICY` 등과 같은 관례.
