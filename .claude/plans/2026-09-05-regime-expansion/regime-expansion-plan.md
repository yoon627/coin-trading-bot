# Goal

선행 3작업([[parameter-search-2026-09]]·[[exit-resolution-verdict-2026-09]]·라이브 의미론 팔)은 전부 **사후 분석**이었다 —
후보를 만든 데이터의 요약통계를 이미 본 뒤에 통계량을 바꿨다. 이 작업은 **아무도 값을 보지 않은 데이터** 위에서
규칙을 먼저 못 박고 판정한다. 이 스레드에서 유일하게 확증(confirmatory)이 가능한 지점이다.

비중첩 200일 창 7개(2020-01-23 ~ 2023-11-22)를 시점 중립 규칙으로 수집하고, **라이브 의미론 팔**(진입·청산 모두
라이브 규약, 240분봉)에서 판정한다. 일봉으로 판정하면 이 스레드가 방금 무효화한 계기를 다시 쓰는 것이다.

라이브 파라미터는 바꾸지 않는다.

# Decisions

## 1) 판정 계기는 라이브 의미론 팔이다

일봉은 경로 의존 게이트(트레일링·부분청산)를 라이브와 다르게 잰다([[exit-resolution-verdict-2026-09]]).
신규 국면을 일봉으로 판정하면 새 데이터를 틀린 계기로 소비하는 것이라, 되돌릴 수 없다.

## 2) 창별 부호검정을 쓰지 않는다

"≥5/7 창 통과" 는 상관된 7개 관측 위의 부호검정이고, 이 스레드가 마켓축(8마켓, 실효 1.22)에서 이미 기각한 통계 형식이다.
7창은 하나의 크립토 매크로 사이클이라 서로 독립이 아니다. 대신 **7창을 이어붙인 pooled 날짜블록 부트스트랩** 하나로 판정한다.
창별 결과는 **진단 표기**로만 낸다.

## 3) 생존편향은 과거로 갈수록 심해지고, 측정 불가다

`krw_markets()` 가 **오늘 상장된** 마켓만 열거하므로 "그 시점 상위 8" 은 실제로 "2026년까지 살아남은 것 중 상위 8" 이다.
후보 풀 자체가 과거로 갈수록 얇아진다 — 미상장 제외 수가 p2020h2 220 / p2021h2 205 / p2023h1 189 이다(오늘 287개 기준).
상장폐지 종목은 Upbit API 가 404 라 표본에 넣을 수도, 편향 크기를 추정할 수도 없다. **결론에 반드시 병기한다.**

# Acceptance

**아래는 결과를 보기 전에 커밋하는 사전고정이다. 실행 후 이 문구를 고치지 않는다.**

1. 7창 D1·240분봉이 시점 중립 규칙으로 수집되고, 기존 4국면·yearly fixture 는 **바이트 단위로 불변**임을 확인한다.
2. 판정 대상은 **둘뿐**이다 — 변형 A(라이브 + 트레일링 1.5/arm 0)와 후보 E(k0.3/TP off/SL7/트레일1.5/arm0).
   새 그리드 탐색을 하지 않는다.
3. **주 통계량**: 7창을 이어붙인 pooled 격차 `G = Σ(후보) − Σ(라이브)`(고정 노셔널 net pnl%, 라이브 의미론 팔).
4. **불확실성**: 청산 달력일 블록 부트스트랩, 블록 = 7창 전체의 청산일 합집합, B=20,000, seed 고정.
5. **발견 선언**: `P(G ≤ 0) ≤ 0.0253`(후보 2개 Šidák) **그리고** 5% 하한 > 0. 둘 다 만족해야 한다.
6. 결과가 어느 쪽이든 그대로 보고한다. 창별 수치는 진단 표기이며 판정에 쓰지 않는다.
7. `./gradlew build` 통과 + wiki 검증 3종 통과.
8. 라이브 무변경 — `TradingProperties`·`deploy/` diff 0.
